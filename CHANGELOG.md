# Changelog

Este projeto usa SemVer, e cada seção agrupa os commits por tipo do Conventional Commits — o
formato deriva dos ADRs [0002](docs/ADR/0002-usar-conventional-commits.md) e
[0004](docs/ADR/0004-usar-semver-para-versionar-o-devflow-ai.md).

Cada release soma uma seção aqui — ver o runbook em [`CONTRIBUTING.md`](CONTRIBUTING.md#release).
